# ClientLiteJSX (CLJ) — UltraCore WASM

The original ClientLiteJSX repository is preserved. The additive C11/WebAssembly compiler, 18 dialects, five keyword encodings, three compact variants, 18 full games, 16 CLJ-authored UI designs, and ZIP import workflows are in [clj-ultracore](clj-ultracore/README.md).

Start with the [detailed README](clj-ultracore/README.md). This release supports a tested language subset, not every JSX/TSX feature or the original OPEN backend.
